## Acceptance Criteria

- [ ] Publish a capability matrix and runtime/storage/model/secrets adapter interfaces, preserving durable case ownership and raw-evidence verification.
- [ ] Select one alternative provider from actual demand and create bounded child issues for runtime, persistence, identity, secrets, deployment and AI capabilities before coding.
- [ ] Keep Streamlit the sole user-facing surface; do not force a separate microservice per component or silently substitute providers.
- [ ] Require full contract and live install/restart/replay verification before marking a provider supported; identify region/cost/source-access constraints.
- [ ] Retain candidate profiles explicitly: Snowflake Tasks/procedures, Google Workflows/Cloud Run Jobs with optional Dataproc or Composer, AWS Step Functions/functions or container jobs, and Azure Durable Functions/activities; Dataproc/Spark is optional batch compute, not the execution engine for every connector.
- [ ] Translate the shared graph into one native execution owner per run; keep provider SDKs and SQL dialects behind adapters, avoid nested competing orchestrators, and use explicit operational-state, evidence-object and analytical-storage adapters.
- [ ] Evaluate authenticated Streamlit-to-workflow connectivity for complete single-provider profiles; hybrid installations are opt-in and no component is silently moved across providers.
- [ ] Normalize native engine states and events into case/run/stage/attempt contracts with correlation IDs and output references; reconcile engine success separately from business assessment and evidence coverage.
- [ ] Choose supported transactional guarantees for operational state separately from object evidence and analytical SQL; document dialect, package and transaction differences instead of treating warehouses as interchangeable databases.
- [ ] Specify rights-safe provider migration of evidence, case versions and reviewer history with stable IDs/hash verification; a new customer installation must not reuse another customer's secrets or silently lose prior audit data.
