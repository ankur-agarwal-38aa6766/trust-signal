- [ ] Enforce tenant/case authorization before retrieval and tool execution.
- [ ] Return traceable citations and abstain on unsupported questions.
- [ ] Record tool/cost traces and verify account/runtime compatibility without assuming entitlement.
- [ ] For a single-organization installation, restrict direct Search service access and tool invocation to approved installation roles; test unauthorized account roles as well as application callers.
