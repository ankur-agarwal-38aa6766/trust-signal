## Acceptance Criteria

- [ ] Provide doctor -> plan -> apply -> smoke-test -> deploy-ui stages or equivalent documented commands, keeping UI deployment deferred to TS-027.
- [ ] Separate UI hosting, durable worker execution, evidence storage and local installation commands; validate account/region/features, identities, network access and estimated spend.
- [ ] Make planning non-mutating, application explicitly approved, repeated installation safe, and partial failure/upgrade reconciliation documented; never overwrite operator credentials.

- [ ] Diagnose billing, API enablement, quotas, runtime packages, SQL resources, permissions and outbound source access before installation; credentials alone cannot make a profile ready, and task schedules remain inactive until approved.
